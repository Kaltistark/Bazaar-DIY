# 大巴扎物品工坊

《The Bazaar》物品卡牌 DIY 工具。上传插画、填写效果，即可实时预览贴近游戏内风格的卡牌，并保存图片分享。

**[在线使用：bazaardiy.kalhark.com](https://bazaardiy.kalhark.com/)**

## 使用方法

1. **设置物品信息**：选择初始品质、小／中／大型、职业和类型标签，填写物品名称。
2. **上传并调整卡图**：支持 PNG、JPG、WebP。在卡框内拖动插画，用滚轮或双指缩放；卡框保持固定。
3. **填写基础效果**：输入主动效果，按需开启被动效果、弹药、初始暴击率和基础多重释放。冷却时间默认 4 秒，整数位与十分位分别调整，可手动输入或使用滚轮、拖动及方向键。
4. **编辑各品质**：点击青铜、白银、黄金、钻石按钮切换。低于初始品质的按钮不可用，传说物品无需切换。未编辑品质会继承已有内容并生成默认强度数值，也可逐级手动调整。增删效果和修改句式默认同步所有可用品质；需要单独调整时，开启编辑区底部的“独立修改当前品质的效果结构”。
5. **按需添加任务和附魔**：展开“任务效果”，设置条件、奖励、目标次数、进度与完成状态；锁定奖励可自动选择显示区域，或手动指定主动／被动区，奖励图标选单直接显示游戏图标。完成基础效果后，进入第二页“附魔效果”，检查自动生成的初稿；每种附魔都可修改、关闭或恢复自动生成，复杂效果可能留空，需要手动填写。
6. **预览并保存图片**：点击“保存图片”，选择全等级或当前等级，可勾选“同时保存附魔效果”，预览区支持自选背景色、上传背景图和重置背景；图片默认跟随预览背景，也可选择透明背景及 1／2／3 倍分辨率。确认预览后下载。全等级图片使用初始品质外观，以对应品质颜色显示各级数值；若各品质的效果结构不一致，则只能保存当前等级。
7. **保存可编辑作品**：使用“保存作品”导出 JSON 文件，之后通过“打开作品”继续编辑。浏览器也会自动保存最近作品；换浏览器、换域名或清除浏览器数据前，建议先导出作品文件备份。

## 网站特色

- **贴近游戏展示风格**：使用游戏素材与字体，呈现品质边框、职业标志、冷却徽章、效果图标及关键词配色。支持八大职业和中立，编辑时实时更新预览。
- **减少重复填写**：名称、插画和裁切位置各品质共用。伤害、治疗、护盾、灼烧、剧毒、生命再生等强度值默认按青铜∶白银∶黄金∶钻石＝1∶2∶3∶4生成；白银起步按2∶3∶4生成。CD、目标数量、时长、百分比和倍率保持不变，手动修改过的品质保留原值，传说物品不缩放。
- **中文效果补全**：支持 `奶60`、`充左`、`加速右2`、`火=伤10%` 等简写，按 Tab 接受补全；也可直接输入完整描述。更多写法见[句式参考](docs/completion-reference.md)。
- **纯图标输入**：输入 `（灼烧）` 或 `(灼烧)`，仅显示对应游戏图标；覆盖全部带图标关键词及别名。增幅效果不会被误识别成卡图上方的自身数值。
- **任务物品展示**：支持任务进度、完成状态、锁定奖励和图标，默认显示未完成，可按品质设置数值与进度。奖励可自动分配或手动选择显示区域。
- **13 种附魔初稿**：根据物品主要效果生成附魔描述，保留手动修改的内容。可将启用且非空的附魔列表一并展示在导出图片的基础效果下方。
- **方便保存与分享**：下载前查看实际导出图片，支持全等级数值合并、透明背景和高清输出；作品文件同时保存基础信息、图片及附魔，方便备份与继续创作。在线使用无需登录。
