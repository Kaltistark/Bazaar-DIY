# 大巴扎物品工坊

浏览器本地运行的《The Bazaar》物品 DIY 编辑器。

## 运行

需要 Node.js 20 或更高版本，无需安装应用依赖。

```sh
npm run dev
```

浏览器打开终端打印的 Local 地址，默认 http://127.0.0.1:5173/。

```sh
npm test
npm run build
```

构建输出位于 `dist/`，可部署到静态托管服务。运行源码时素材在 `public/assets/`，构建时复制为 `dist/assets/`。

## 使用

1. 选择初始品质、尺寸、职业和类型，输入名称。
2. 上传 PNG/JPG/WebP 插画；在卡框区域拖动图片，用滚轮、缩放滑条或双指缩放调整位置。边框保持固定。
3. 输入主动和被动效果。输入 `60火`、`60伤` 等简写，按 Tab 接受虚化的补全；已有伤害效果时支持 `火=伤`。
4. 切换品质编辑数值。未编辑等级继承最近已编辑的较低等级；名称、图片和裁切等基础信息共用。默认增删效果、调整句式会同步所有可用品质，并保留已编辑等级原有数值。只有勾选“独立修改当前品质的效果结构”后，结构变化才仅作用于当前品质。
5. 弹药和初始暴击率默认关闭，可按品质开启和设置。
6. 展开“任务效果”添加任务。条件、奖励、右侧图标和可选锁定奖励分别设置；目标次数默认从条件自动读取，也可手动覆盖。进度默认零，可填写或勾选已完成。任务增删和句式遵循相同的跨品质同步规则，数值与进度按品质编辑。
7. 导出默认合并全等级数值、使用初始品质外观；跨等级效果结构不同时，仅允许导出当前等级。可选择深色或透明背景、1/2/3倍分辨率。全等级图使用初始品质的任务进度与锁定状态，并合并目标和奖励数值。

浏览器会自动保存最近作品。使用“保存作品”导出可编辑 JSON，再用“打开作品”恢复。清除浏览器数据或换域名会影响本地保存，作品文件可用于迁移和备份。

## 结构

- `src/model.js`：品质继承、结构检查、数值合并、补全、作品校验。
- `src/renderer.js`：Canvas 排版；预览和 PNG 导出使用同一绘制器。
- `src/app.js`：编辑器、图片交互、本地存储、导入导出。
- `src/data.js`：品质、尺寸、职业、类型、关键词配置。
- `public/assets/assets-manifest.json`：游戏原始素材清单、尺寸和九宫格边界。
- `docs/asset-sources.md`：图标、字体与高清化来源。

参考素材优先于数据库描述。价格、卡面底部弹药、外围游戏 UI、关键词解释框不参与绘制。
