# 增幅物品与关键词图标核对

核对时间：2026-10-11。以本机原游戏 `TheBazaar_Data/StreamingAssets/GameData.db.zip` 中的卡牌数据、原始卡图纹理及项目中的游戏截图为准。

| 原游戏物品 | 本机数据中的效果 | 展示核对 |
| --- | --- | --- |
| Apropos Chapeau | 己方物品获得伤害、治疗、护盾增幅；白银／黄金／钻石的各项增幅为 6／9／12 | 增幅使用自定义属性存储，作用目标是其他物品，没有自身伤害、治疗、护盾徽章 |
| Grindstone | 左侧武器获得 10／20／30 伤害；左侧物品 CD 超过 5 秒时额外多重释放 | 伤害增幅作用于左侧武器，不生成磨石自身的伤害徽章 |
| Cloud Tanker | 相邻物品获得 20／40／60 伤害及 3／6／9 灼烧 | 两项都是给相邻物品的增幅，不生成自身伤害、灼烧徽章 |
| 私人喷气机（Private Jet） | 自身及一件物品开始飞行；相邻物品按各自价值获得伤害、护盾、治疗增幅 | 与项目中“飞行 价值 增益.jpg”的无顶部数值展示一致 |

前三项增幅在原数据中使用 `TActionCardModifyAttribute`，目标为指定物品位置或己方物品区域。它们与直接伤害、治疗、护盾、灼烧等对玩家生效的效果有区别。复制原数值后检查当前品质及全品质导出，增幅数字保留在效果区。

作为对照，项目中的药房截图（“剧毒 灼烧 生命再生.jpg”）具有自身的灼烧、剧毒和再生效果，顶部应继续保留对应徽章。混合物品只排除给其他物品的增幅，不排除直接输出。

## 输入与附加属性

- `（关键词）` 与 `(关键词)` 支持全部已有图标的关键词及别名，只画对应游戏图标，保留输入位置。无图标或未知关键词保留文字。
- 图标形式仍参与强度缩放、全品质数值合并和自动附魔分析；不会改变存档中的原始描述。
- 基础多重释放默认关闭，基础次数为 1；启用后可按品质编辑，主动区域单独显示，全品质图片合并不同次数。
- 任务锁定奖励可自动选择主动／被动区域，也可手动指定。条件触发、永久增益和属性修正倾向被动；直接输出及主动增幅倾向主动。复杂描述可手动覆盖。
- 奖励图标选单使用原有游戏图标，支持鼠标与键盘选择。

参考核对：[BazaarDB 的 Apropos Chapeau](https://bazaardb.gg/card/6p59sh4nc4xlq5yzh0ptd80nlt/Apropos-Chapeau)。其在线数值与本机资源存在差异，本次测试使用上表中的本机数值，不用在线数值覆盖游戏素材。
