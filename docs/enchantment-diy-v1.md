# DIY 附魔初版

依据项目内“总结物品附魔效果规律”对话及 `enchantment-patterns.md`，并核对 BazaarDB 的 Caracal、Uwashiwali Bird、Pufferfish、Pasta、Lens 和 Beach Ball。展示颜色遵循用户提供的游戏附魔选单：闪亮米白、长青黄绿、辉耀浅绿。

生成范围刻意有限：直接的伤害、治疗、护盾、剧毒、灼烧、再生量识别为主属性，同属性附魔翻倍，跨属性使用引用句式。伤害／治疗／护盾转持续属性为10%，持续属性转直接属性为5倍；不把公式数值写死，因此品质变化后引用仍有效。多项直接主属性存在歧义时，跨属性留空。

主动辅助卡可生成控制、闪亮、辉耀的初稿；已有控制时长用翻倍句式。复杂触发、任务、出售、成长、转化、自毁和纯被动不自动新增主动能力。沉重2秒、寒冰0.5秒、疾速2秒只是可修改的初稿默认值，不是对所有物品适用的游戏规则。复杂经济物品的黄金附魔也可能需要作者修改。

附魔描述各品质共用；手动修改或留空会受到保护。关闭和留空的行不参与展示与导出。此页展示的是13种可选附魔的效果清单，不会把全部附魔同时叠加到基础卡数值上。

首版不处理逐物品特例、战斗结算、百分比取整、附魔后基础图数值重算和逐品质自定义附魔描述。附魔及开关会随作品JSON保存，旧版作品会自动补齐空附魔字段。
