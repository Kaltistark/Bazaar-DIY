# Tab 补全句式

句式参考 BazaarDB 的代表卡牌，并优先沿用项目中游戏截图的中文用语。简写、默认 1 秒和数值单位转换是编辑器约定，不是卡牌的默认游戏数值；只有按 Tab 才会替换输入。

## 输入约定

| 输入                                                          | 结果或用途                                                                  |
| ------------------------------------------------------------- | --------------------------------------------------------------------------- |
| `奶60` / `60奶` / `回血60`                                    | 治疗60生命值。                                                              |
| `火60` / `60灼烧`、`毒12`、`盾80`、`伤60`、`再生6`            | 主动基础效果                                                                |
| `充左` / `充左2.5`                                            | 为左侧物品充能1秒 / 2.5秒。                                                 |
| `加速右2`、`冻敌2件1.5`、`充邻科技2`                          | 方向、数量、类型和时长                                                      |
| `左` / `右` / `邻` / `自` / `全` / `敌` / `双方` / `其他`     | 左侧 / 右侧 / 相邻 / 此物品 / 己方所有 / 敌方所有 / 双方所有 / 己方所有其他 |
| `武` / `食` / `科` / `友` / `水` / `乐` / `小` / `中` / `大`  | 武器 / 食物 / 科技 / 伙伴 / 水系 / 乐器 / 小型 / 中型 / 大型                |
| `充非玩具2`                                                   | 为一件非玩具物品充能2秒。                                                   |
| `开战：盾100`、`战后奶60`、`开日：永久价值+1`                 | 战斗或每日触发                                                              |
| `用邻：充自1`、`用武器加速右2`、`冻结时：奶60`、`得盾：充自1` | 使用、触发、获得的被动句式                                                  |
| `左伤+10`、`全暴击+20`、`永久伤+10`                           | 物品属性增长                                                                |
| `cd-0.5` / `左cd-10%`                                         | 冷却时间缩短                                                                |
| `火=伤` / `火=伤10%` / `毒=10%伤` / `盾=5倍火`                | 等同于、百分比和倍数；引用物品属性时须先有对应效果                          |
| `高温：火60` / `霜冻：奶60`                                   | 朱尔斯温度条件；霜冻与冻结分别识别                                          |
| `转左伙伴` / `转左为武器` / `升级右`                          | 转化与升级                                                                  |
| `奶1.5k` / `伤2万` / `奶１２０`                               | 千、万和全角数字                                                            |

主动、被动和任务奖励共用补全；任务条件仍自由输入，避免把任务要求误写成战斗效果。多行只处理光标位于行末的当前行。存在选区、输入法正在组字、已完成句子或不能明确识别的目标时，不拦截 Tab。

## 参考来源

- [Lens](https://bazaardb.gg/card/kqg286bv9kckzjycgc5ncgh1ls/Lens)：右侧科技物品目标、受到加速后充能自身。
- [Mini Keyboard](https://bazaardb.gg/card/gzwf4lbnb82mtxbclg47hm95tf/Mini-Keyboard)：相邻乐器与相邻科技目标。
- [Speedrunner](https://bazaardb.gg/card/5bd84hlpd8tpxs7s04882hjsdt/Speedrunner)：非玩具目标、使用相邻玩具的触发。
- [Assembly Line](https://bazaardb.gg/card/nz1mbf6mlmmqvmjl48ns48ykl0/Assembly-Line)：战后转化左侧物品、每日开始时升级。
- 本地 `参考素材/治疗.jpg`、`加速.jpg`、`充能.jpg`、`等同于.jpg`：中文治疗、使用、充能与等同于句式。
- [keyword-styles.json](../public/assets/keyword-styles.json)：游戏 `TooltipTypography` 原始颜色与图标配置。高温、霜冻为无图标纯色；转化与升级使用各自的原始图标。

没有把这些卡牌的数值当作 DIY 平衡限制，也没有运行时依赖 BazaarDB；离线仍能补全。
